# Планы

Порядок примерно по соотношению «польза / сложность».

## Сделано

- [x] **Сервер**: systemd, AmneziaWG из исходников, пул портов, панель.
- [x] **Клиент Windows**: отдельное окно на Electron, трей, служба-помощник без
      UAC на каждый запуск.
- [x] **Установщик клиента одним .exe** — `tools/build-installer.ps1` собирает
      `NurofenSetup.exe` через Inno Setup. Адрес сервера вшит в установщик;
      пользователь получает один файл.
- [x] **Пользовательские сети как в Radmin VPN** — создание и подключение по
      названию и паролю, отдельные подсети и изоляция на одном сервере.
- [x] **Несколько сетей сразу** — у каждой свой интерфейс `nurofen`,
      `nurofen-2`, …; вкладки только переключают, какую сеть видно.
- [x] **Автообновление клиента** — манифест версии, архив `client.zip`,
      проверка SHA-256, замена файлов и перезапуск; при защищённой папке —
      один запрос прав администратора.
- [x] **Передача файлов** — согласие получателя, прямой поток по туннелю,
      проверка SHA-256 и прогресс.
- [x] **Удалённая помощь** — просмотр экрана и управление только с явного
      согласия принимающей стороны, индикатор и остановка сеанса; плавный
      поток до 1280×720 около 15 кадров/с с резервным захватом.
- [x] **Пасхалка в версии** — пять кликов по версии в главном окне показывают
      рисунок на две секунды.
