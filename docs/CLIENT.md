# Windows-клиент

## Что устанавливается

`install.ps1` (от администратора):

1. Копирует приложение в `%LOCALAPPDATA%\Nurofen\app`.
2. Если системного Node.js 22+ нет — скачивает переносимый в
   `%LOCALAPPDATA%\Nurofen\runtime\node.exe`.
3. Ставит официальный **AmneziaWG** (`amnezia-vpn/amneziawg-windows-client`,
   MSI, тихая установка), если его нет.
4. Создаёт службу `NurofenHelper` (LocalSystem) — она поднимает и опускает
   туннель, поэтому клиенту не нужен UAC на каждый запуск.
5. Кладёт токен помощника в `C:\ProgramData\Nurofen\helper-token` (чтение —
   всем, запись — только SYSTEM/админам).
6. Создаёт ярлыки: рабочий стол, меню «Пуск», автозапуск (с флагом
   `--no-window`).
7. Запускает клиент.

Параметры:

```powershell
.\install.ps1 -Server http://1.2.3.4:8787   # адрес по умолчанию в форме входа
.\install.ps1 -NoAutostart                 # без автозапуска
.\install.ps1 -SkipAwg                     # не ставить AmneziaWG (уже есть)
```

## Как пользоваться

1. Ввести код приглашения (и адрес сервера, если он не задан установщиком).
2. Нажать переключатель в правом верхнем углу.
3. Скопировать свой адрес и отправить друзьям.

Для Minecraft: открыть мир → «Открыть для сети» → клиент сам увидит порт в логе
игры и сообщит его серверу. У друзей в строке с вашим именем появится кнопка
**«Зайти»**: она копирует адрес `10.66.0.11:54321` и добавляет мир в
`servers.dat`, после чего он виден в «Сетевой игре» (перед записью клиент
делает бэкап `servers.dat.nurofen.bak`).

> В самом списке миров Minecraft он не появится «сам собой»: WireGuard — L3-сеть,
> broadcast от Minecraft через неё не проходит. Кнопка «Зайти» — это замена
> автопоиску, а не костыль поверх него.

## Где что лежит

| Путь | Что |
|---|---|
| `%APPDATA%\Nurofen\client.json` | профиль: токен, приватный ключ, адрес сервера |
| `%APPDATA%\Nurofen\client.log` | журнал клиента |
| `C:\ProgramData\Nurofen\helper.log` | журнал службы-помощника |
| `C:\ProgramData\Nurofen\conf\nurofen.conf` | сгенерированный конфиг AmneziaWG |

Кнопка «Диагностика» в клиенте показывает состояние службы, наличие AmneziaWG и
последние строки журнала.

## Телефон, macOS, Linux

В карточке «Сеть» есть «Конфиг для телефона»: клиент регистрирует **отдельное
устройство** в сети, генерирует для него пару ключей и отдаёт готовый `.conf`.
Его можно импортировать в официальное приложение AmneziaWG (Android, iOS,
macOS, Linux) — устройство получит свой адрес и будет видеть остальных.

Ограничения такого профиля: у него нет доступа к панели (только туннель), и
пропал он из списка не сразу — сервер считает устройство офлайн по отсутствию
heartbeat.

## Проблемы и решения

| Симптом | Причина | Решение |
|---|---|---|
| «AmneziaWG не установлен» | MSI не поставился | поставить вручную с github.com/amnezia-vpn/amneziawg-windows-client, затем перезапустить клиент |
| «Нужны права администратора» | клиент запущен без службы-помощника | `install.ps1` от админа, `sc query NurofenHelper` |
| Сеть включается, но друзья не пингуются | порт зарезан / MTU / firewall VPS | см. [DPI.md](DPI.md) |
| Всё было хорошо, перестало | сменились параметры на сервере | переподключиться (клиент сделает это сам при перезапуске) |
| Клиент не стартует | занят порт 39391 | закрыть старое окно/процесс `node` |
| Окно не открывается | нет Edge/Chrome | поставьте любой Chromium-браузер, либо откройте `http://127.0.0.1:39391` вручную |

## Удаление

```powershell
.\uninstall.ps1              # снести всё, включая профиль
.\uninstall.ps1 -KeepProfile # сохранить ключи и настройки
```

AmneziaWG удаляется отдельно через «Программы и компоненты», если он больше не
нужен для других целей.
