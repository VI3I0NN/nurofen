# Windows-клиент

## Что устанавливается

`install.ps1` (от администратора):

1. Копирует приложение в `%LOCALAPPDATA%\Nurofen\app`.
2. Кладёт рядом оболочку Electron (`app\electron`) и её код (`app\electron-app`),
   поэтому отдельный браузер на компьютере не нужен.
3. Если системного Node.js 22+ нет — скачивает переносимый в
   `%LOCALAPPDATA%\Nurofen\runtime\node.exe`.
4. Ставит официальный **AmneziaWG** (`amnezia-vpn/amneziawg-windows-client`,
   MSI, тихая установка), если его нет.
5. Создаёт задачу планировщика `NurofenHelper` (SYSTEM, при загрузке) — она
   поднимает и опускает туннели, поэтому клиенту не нужен UAC на каждый запуск.
6. Кладёт токен помощника в `C:\ProgramData\Nurofen\helper-token` (чтение —
   всем, запись — только SYSTEM/админам).
7. Создаёт ярлыки: рабочий стол, меню «Пуск», автозапуск с флагом `--hidden`
   (окно не открывается, клиент сразу живёт в трее).
8. Запускает клиент.

Параметры:

```powershell
.\install.ps1 -Server http://1.2.3.4:8787   # адрес по умолчанию в форме входа
.\install.ps1 -NoAutostart                 # без автозапуска
.\install.ps1 -SkipAwg                     # не ставить AmneziaWG (уже есть)
```

## Как пользоваться

1. Выберите действие: **«Создать сеть»** или **«Подключиться»**.
2. Создатель задаёт название сети и пароль. Остальные вводят те же название и
   пароль. Адрес сервера уже задан установщиком и вручную не вводится.
3. Нажмите круглую кнопку питания в карточке устройства — она включает и
   выключает выбранную сеть. Рядом видны имя устройства, его адрес и состояние.
4. Ниже — карточка сети: название и список участников с адресами. У каждого
   участника показано, **в сети он или нет**, а у тех, кто в сети, — пинг.
5. Сообщите друзьям название сети и пароль — устройства из других сетей не
   видят участников вашей сети. Пароль клиент не сохраняет: после «Выйти» его
   нужно ввести снова.

### Ник

Ник — это имя вашего устройства, которое видят остальные участники. Изменить
его можно тремя способами:

- нажать карандаш рядом с именем в карточке устройства;
- выбрать **«Сеть → Изменить ник…»**;
- в меню **«Система»** также есть этот пункт.

Ник должен содержать от 2 до 32 символов. Новое имя сразу отправляется на
сервер для всех сетей, в которых вы состоите, и сохраняется в профиле. Если
какая-то сеть в этот момент недоступна, клиент сообщит об этом — повторите
сохранение позже.

### Статусы и пинг

В списке участников у каждого устройства есть подпись **«В сети»** или
**«Не в сети»** и значение пинга:

- «В сети» — устройство недавно отмечалось на сервере (раз в 5 секунд).
  При выходе из сети статус меняется на «Не в сети» сразу.
- Пинг измеряется по ICMP между вашим устройством и устройством участника
  через туннель. Значения до 80 мс подсвечены зелёным, до 160 мс — жёлтым,
  выше — красным.
- «Нет ответа» означает, что устройство в сети, но не отвечает на ICMP —
  например, из-за брандмауэра. Это не ошибка клиента.
- В строке состояния внизу показан пинг до сервера («до сервера … мс»).

Пинг между двумя участниками складывается из их маршрутов до сервера: трафик
идёт через общий узел, а не напрямую. Поэтому у друзей из разных городов
задержка равна сумме задержек каждого до сервера.

### Прямые соединения (бета)

Под карточкой устройства есть переключатель **«Прямые соединения»** с меткой
**«бета»**. По умолчанию он выключен, и весь трафик идёт через сервер — это
основной и самый надёжный способ.

Если включить его **у обоих участников**, клиенты попробуют связаться
напрямую, минуя сервер. Тогда пинг между ними может заметно снизиться, но
работает это не всегда: соединение зависит от NAT и провайдера. Если прямой
канал не поднялся за 8 секунд, клиент сам возвращается на маршрут через
сервер и повторяет попытку не раньше чем через 30 минут — сеть при этом не
рвётся, а в журнале появляется запись о неудачной попытке.

Особый случай — два компьютера за одним роутером (один внешний IP): пакеты
на внешний адрес второго компьютера роутер обычно не пропускает обратно
(нет hairpin NAT). Для таких пар клиенты обмениваются локальными адресами
(например, 192.168.1.50) и строят прямой канал внутри домашней сети.

Рядом с пингом участника видно, каким путём идёт трафик: «напрямую» или
«через сервер». Сети, сервер и остальные функции от переключателя не зависят.

### Брандмауэр и пинг

Чтобы участники могли пинговать друг друга и принимать входящие подключения
(например, для игры по локальной сети), клиент добавляет в брандмауэр Windows
правила: `Nurofen-LAN-ICMP`, `Nurofen-LAN-TCP`, `Nurofen-LAN-UDP`. Они
разрешают входящий трафик **только из виртуальной сети** `10.66.0.0/16`, а не
из обычной локальной сети, и действуют для всех профилей. Для прямых
соединений добавляется `Nurofen-Direct-UDP` — входящий UDP только на порты
собственных туннелей клиента; неподписанные пакеты AmneziaWG отбрасывает сам.

Правила добавляет служба-помощник при запуске, установщик и обновление. Вместе
с клиентом обновляется и служба: после замены файлов клиент просит её
перезапуститься и ждёт, пока она ответит новой версией. В «Диагностике» видно
текущую версию службы; если она старше клиента, там появляется кнопка
**«Обновить службу»**. Для самых старых версий Windows один раз спросит права
администратора — это нормально.

### Несколько сетей

Сети показываются вкладками над карточкой устройства. Кнопка **«+»** или
**«Сеть → Добавить сеть…»** добавляет ещё одну сеть. Вкладка с зелёной точкой
включена; переключение вкладок не выключает остальные сети — они продолжают
работать одновременно, каждая на своём сетевом интерфейсе (`nurofen`,
`nurofen-2`, …).

Чтобы убрать сеть, выберите её вкладку и нажмите **«Сеть → Выйти из сети…»**:
клиент отключит туннель и отзовёт своё устройство на сервере.

### Меню и трей

Команды собраны в меню сверху: **«Система»** (обновления, диагностика,
настройки, выход), **«Сеть»** (изменить ник, добавить сеть,
включить/отключить, выйти из сети), **«?»** (о программе).

В **«Система → Настройки…»** можно выбрать светлую или тёмную тему,
компактный список участников, автоподключение при запуске и бета-режим
прямых соединений для выбранной сети. Настройки оформления и автоподключения
сохраняются в локальном профиле.

Клиент работает в одном экземпляре: повторный запуск не открывает второе окно,
а выводит на передний план уже открытое. Закрытие окна не завершает программу —
оно скрывает его в трей, и сети продолжают работать в фоне. Левый клик по
иконке в трее открывает окно, правый — меню с пунктами «Открыть», «Включить /
Отключить сеть» и «Выход». Полностью закрыть клиент можно через
**«Система → Выход»** или пункт «Выход» в меню трея.

## Обновления

Клиент раз в несколько часов спрашивает у сервера версию
(`/api/v1/client/latest`) и показывает её в **«Система → Обновления…»**. Там же
видны версии клиента и службы-помощника.

Кнопка «Установить» скачивает `client.zip`, проверяет SHA-256, распаковывает и
заменяет файлы клиента. Затем клиент перезапускает службу-помощник и ждёт,
пока она ответит новой версией, после чего окно перезапускается само. Служба и
клиент всегда должны быть одной версии — это проверяется автоматически.

Кнопка **«Принудительно обновить службу»** заново скачивает и проверяет пакет,
переустанавливает файлы даже если номер версии тот же, затем с правами
администратора завершает и запускает задачу службы `NurofenHelper`. Клиент
проверяет ответ `/health` и показывает фактически запущенную версию. Кнопка
доступна в окне обновления и диагностики.

Если программа установлена в `C:\Program Files`, Windows один раз попросит
права администратора — это нормально. Настройки, профили сетей и ключи при
обновлении не трогаются: обновляется только код.

## Где что лежит

| Путь | Что |
|---|---|
| `%APPDATA%\Nurofen\client.json` | профиль: список сетей, токены, ключи, имена и адреса |
| `%APPDATA%\Nurofen\client.log` | журнал клиента |
| `C:\ProgramData\Nurofen\helper.log` | журнал службы-помощника |
| `C:\ProgramData\Nurofen\conf\*.conf` | сгенерированные конфиги AmneziaWG |

«Диагностика» в клиенте показывает состояние службы, наличие AmneziaWG,
интерфейсы всех сетей и последние строки журнала.

## Проблемы и решения

| Симптом | Причина | Решение |
|---|---|---|
| «AmneziaWG не установлен» | MSI не поставился | поставить вручную с github.com/amnezia-vpn/amneziawg-windows-client, затем перезапустить клиент |
| «Нужны права администратора» | клиент запущен без службы-помощника | `install.ps1` от админа, проверьте задачу `NurofenHelper` в планировщике |
| «Нет ответа» вместо пинга участника | на его компьютере брандмауэр блокирует ICMP, либо он на старой версии клиента | попросите его обновиться и перезагрузить ПК; правила `Nurofen-LAN-*` добавляются автоматически |
| Сеть включается, но друзья не пингуются | порт зарезан / MTU / firewall сервера | см. [DPI.md](DPI.md) |
| Всё было хорошо, перестало | сменились параметры на сервере | переподключиться (клиент сделает это сам при перезапуске) |
| Порт 39391 занят другой программой | второй экземпляр не нужен, а порт держит чужой процесс | закройте программу-владельца; сам Nurofen второй экземпляр не запускает — он показывает уже открытое окно |
| Окно не открывается | оболочка Electron не запустилась или завис процесс | завершите `electron.exe` в диспетчере задач и запустите ярлык Nurofen снова; при повторной ошибке переустановите клиент |
| «Обновлений нет» | на сервере ещё лежит старая версия | повторите позже; обновление публикуется вместе с установщиком |

## Удаление

```powershell
.\uninstall.ps1              # снести всё, включая профиль
.\uninstall.ps1 -KeepProfile # сохранить ключи и настройки
```

AmneziaWG удаляется отдельно через «Программы и компоненты», если он больше не
нужен для других целей.
