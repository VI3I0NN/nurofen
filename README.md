# Nurofen

Виртуальная локальная сеть для игры с друзьями — как Radmin VPN, только на вашем
сервере, с вашими ключами и с обфускацией, рассчитанной на российские ТСПУ.

Разработчик — VI3I0NN.

Главный сценарий: **собраться компанией и поиграть в Minecraft по сети**, не
пробрасывая порты и не светя домашний IP.

```
   друг A            друг B            друг C          (одна из сетей)
  10.66.0.11        10.66.0.12        10.66.0.13
      │                 │                 │
      └──────── AmneziaWG (UDP, обфускация) ────────┐
                                                   │
                                            ┌──────▼──────┐
                                            │  сервер     │  10.66.0.1
                                            │  nurofen    │  панель :8787
                                            └─────────────┘
```

Каждая сеть получает свою подсеть `10.66.<n>.0/24`; участники разных сетей друг
друга не видят.

## Что умеет

- **Модель Radmin VPN** — пользователи создают сети с названием и паролем;
  остальные подключаются к нужной сети по этим данным. Сети изолированы друг
  от друга.
- **Несколько сетей сразу** — вкладки в окне переключают сети; каждую можно
  включить отдельно, и они работают одновременно, каждая на своём интерфейсе.
- **Свой ник** — имя устройства меняется в пару кликов и сразу обновляется у
  всех участников во всех сетях.
- **Статусы и пинг** — у каждого участника видно «В сети» или «Не в сети», а
  для онлайн-устройств — задержку ICMP через туннель; пинг до сервера показан
  в строке состояния. Для виртуальной сети автоматически открываются правила
  брандмауэра, чтобы участники могли пинговать друг друга.
- **Прямые соединения (бета)** — отдельный переключатель на каждую сеть: если
  включён у обоих участников, клиенты пробуют связаться напрямую и обойти
  сервер. Неудачная попытка автоматически возвращается на маршрут через
  сервер, поэтому режим не влияет на стабильность сети.
- **Одна кнопка** — включить сеть и скопировать адрес для игры с друзьями.
- **Minecraft в один клик** — когда мир открыт для сети, у участников появляется
  кнопка «Добавить»: адрес добавляется в «Сетевую игру» и копируется в буфер.
  Достаточно обновить список серверов в игре. Свой адрес мира виден отдельной
  строкой над списком участников.
- **Статус мира** — клиент сам опрашивает мир по протоколу Minecraft и показывает
  MOTD, число игроков, версию и задержку; рядом с «Добавить» у участника видно,
  сколько сейчас играет. Моды и файлы игры не нужны.
- **«Друг открыл мир»** — тост в окне и уведомление в трее, когда участник
  открывает мир. Отключается в настройках.
- **Nurofen Play** — отдельное окно: выбираете сборку Prism Launcher или
  PineconeMC, видите миры друзей и запускаете игру уже подключённой к нужному
  миру. Используется штатный запуск лаунчера `-l <сборка> -s <адрес>`, поэтому
  версия, моды и аккаунт остаются вашими. Для TLauncher Legacy мир записывается
  в «Сетевую игру», после чего открывается сам лаунчер. Nurofen не скачивает
  игру и не хранит пароли аккаунтов.
- **Ссылка-приглашение** — «Пригласить в сеть…» копирует ссылку
  `nurofen://join?…`; у друга форма подключения заполняется сама. В ссылке
  лежит пароль сети, поэтому пересылайте её только тем, кому доверяете.
  Если сеть была создана до `0.4.31`, пароль один раз нужно ввести заново —
  клиент сохранит его для ссылки.
- **Любой лаунчер** — папка игры находится сама (`.minecraft`, TLauncher Legacy,
  Legacy Launcher, Prism, PineconeMC, MultiMC, Modrinth, ATLauncher, GDLauncher,
  CurseForge) или указывается вручную в настройках.
- **Свой сервер** — можно указать папку с `server.jar`: пока сервер запущен,
  друзьям раздаётся его адрес, порт берётся из `server.properties`.
- **Без браузера** — окно на Electron вшито в установщик, у всех друзей оно
  выглядит одинаково. Закрытие прячет окно в трей, сеть продолжает работать в
  фоне; автозапуск стартует сразу в трее.
- **Обновление с сервера** — клиент сам проверяет версию и подтягивает новые
  файлы; установщик для обновления не нужен.
- **Обход ТСПУ** — AmneziaWG (обфусцированный WireGuard) со случайными параметрами
  на каждой установке + пул портов, которые клиент перебирает сам.
- **Ноль зависимостей** — сервер и клиентский backend на чистом Node.js, без
  `npm install`; Electron едет внутри установщика.
- **Свой сервер** — никаких чужих аккаунтов, подписок и телеметрии.

## Быстрый старт

### 1. Сервер на VPS

Ubuntu 22.04/24.04 или Debian 12+, root, публичный IPv4:

```bash
git clone https://github.com/VI3I0NN/nurofen.git
cd nurofen
sudo bash server/install/install.sh --host <ваш-ip>
```

Установщик поставит Node.js, AmneziaWG, настроит systemd и откроет порты. Новая
установка сервера начинает без сетей — первую сеть создайте в клиенте. В конце
будет напечатан **токен админ-панели**. Панель:
`http://<ваш-ip>:8787/admin`.

Подробности и требования — [docs/DEPLOY.md](docs/DEPLOY.md).

### 2. Клиент на Windows

**Вариант A — готовый .exe (рекомендуется для друзей):**

Скачайте установщик с сервера: **http://201.58.187.214:8787/** — эту ссылку можно
просто отправить друзьям, страница сама предложит `NurofenSetup.exe`. Запустите,
нажмите «Далее» — установщик сам скачает Node.js и AmneziaWG, зарегистрирует
службу-помощник, положит ярлыки и настроит адрес сервера. Окно клиента —
отдельное приложение на Electron, браузер на компьютере не требуется.

Собрать установщик самому (Inno Setup 6/7):

```powershell
# собрать установщик с адресом сервера
.\tools\build-installer.ps1 -Server http://<ваш-ip>:8787
```

**Вариант Б — PowerShell (для разработки):**

```powershell
# в папке client, из PowerShell от администратора
.\install.ps1 -Server http://<ваш-ip>:8787
```

Установщик скачает переносимый Node.js, поставит официальный клиент AmneziaWG,
зарегистрирует службу-помощник и создаст ярлык. В клиенте создайте сеть или
подключитесь к существующей по названию и паролю.

Подробности — [docs/CLIENT.md](docs/CLIENT.md).

## Как это работает

1. Клиент генерирует **свою** пару ключей X25519 для каждой сети. Приватный ключ
   не покидает компьютер — на сервер уходит только публичный.
2. Сервер выдаёт адрес в сети, запоминает публичный ключ и отдаёт параметры
   обфускации, адрес хаба и список портов.
3. Клиент собирает конфиг AmneziaWG и поднимает интерфейс через службу-помощник
   (без UAC на каждый запуск). Для каждой добавленной сети — свой интерфейс,
   поэтому несколько сетей работают одновременно.
4. Клиент пингует хаб — так проверяется, что туннель реально работает, — и
   участников сети, чтобы показать задержку до каждого. Если порт зарезан,
   берётся следующий из пула.
5. Обновления клиент берёт с того же сервера: манифест версии, архив с файлами,
   проверка SHA-256 и перезапуск.
6. Дальше это обычная L3-сеть: любая LAN-игра, файлы, RDP — что угодно по
   адресам `10.66.x.x`.

Описание внутренностей — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Про ТСПУ

Обычный WireGuard в России детектируется по характерному заголовку и размерам
пакетов, поэтому здесь используется AmneziaWG: случайные junk-пакеты перед
рукопожатием, свои значения `H1..H4`, `S1/S2`, нестандартный порт и пул
дополнительных портов через `iptables REDIRECT`.

Что делать, если провайдер всё же зажал канал — [docs/DPI.md](docs/DPI.md).

Важно: обфускация помогает против фильтрации по сигнатурам, но не спасает от
полного отключения UDP у провайдера (например, мобильные операторы в период
ограничений). TCP-транспорт (VLESS/REALITY) в планах — [docs/ROADMAP.md](docs/ROADMAP.md).

## Ограничения

- **API без TLS по умолчанию.** Пароли сетей и токены идут по HTTP; для
  параноидального режима поставьте перед сервером Caddy/nginx и укажите
  `https://` адрес. См. [docs/SECURITY.md](docs/SECURITY.md).
- **Только Windows-клиент.** Android/iOS/macOS отдельным приложением Nurofen не
  поддерживаются.
- **Автообновление меняет только код клиента.** Новую версию Electron или
  службы-помощника по-прежнему ставит установщик.
- **TLauncher Legacy без авто-подключения.** У TLauncher нет документированного
  флага «запустить эту сборку и войти на сервер», поэтому Nurofen Play пишет мир
  в `servers.dat` и открывает лаунчер: профиль и версию игрок выбирает сам.
  Для Prism Launcher и PineconeMC подключение к миру происходит сразу.

## Структура репозитория

```
server/            координационный сервер (Node.js, без зависимостей)
  src/             API, выдача адресов, рендер и применение конфигов AWG
  install/         установщик и unit для systemd
  test/            smoke-тесты API
client/            Windows-клиент (Node.js + Electron-оболочка + трей)
  src/ui/          интерфейс
  electron/        оболочка окна и трея
  install.ps1      установка клиента
docs/              архитектура, деплой, DPI, безопасность
tools/             сборка .exe-установщика (Inno Setup), генератор иконки
dist/              NurofenSetup.exe — готовый установщик
```
